## Why this repository exists

The project moved to its own GitHub organization. GitHub normally redirects a
transferred repository's URL automatically, but that redirect does not survive
a second transfer — and this address had already been shared in conference
submissions and written material.

Rather than leave those links returning 404, this repository stands at the old
address and points at the new one. It holds no code and takes no issues or pull
requests; open those on the repository above.

The documentation URL is redirected properly, at
[sandeepbazar.github.io/ocm-mcp-server](https://sandeepbazar.github.io/ocm-mcp-server/).
